# Task 21 — Basic SQL SELECT

**Track:** Data Analytics  
**Level:** 1  
**Day:** 21  
**Topic:** Basic SQL SELECT  
**Tools:** MySQL / PostgreSQL  
**Dataset:** Northwind-style sample dataset

## Objective
Build SQL fundamentals by writing simple `SELECT`, `WHERE`, and `ORDER BY` queries.

## Deliverables
- `schema_and_data.sql` — creates the sample Customers, Products, and Orders tables and inserts data.
- `queries.sql` — 10 completed SQL queries.
- `query_outputs/` — output for every query in CSV and TXT format.
- `task21.db` — SQLite database containing the same sample data for quick testing.
- `README.md` — task documentation.

## How to run
1. Create/load the tables using `schema_and_data.sql`.
2. Run the statements in `queries.sql`.
3. Compare your results with the files in `query_outputs/`.

The SQL uses basic commands only: `SELECT`, `WHERE`, and `ORDER BY`, with no joins or aggregation, matching the task scope.
