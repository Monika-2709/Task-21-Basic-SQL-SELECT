# Task 21 – Basic SQL SELECT

## 📌 Overview

This project is part of my **Data Analytics Track – Level 1, Day 21**.

The task focuses on building SQL fundamentals by writing simple queries using:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `ASC`
* `DESC`
* `BETWEEN`

## 🎯 Objective

Practice retrieving, filtering, and sorting data using basic SQL queries.

## 🛠️ Tools

* MySQL
* PostgreSQL
* SQLite

## 📊 Dataset

A Northwind-style `Products` dataset was used for practicing SQL queries.

Main columns include:

* ProductID
* ProductName
* Category
* UnitPrice
* UnitsInStock

## 🔎 Queries Completed

A total of **10 SQL queries** were created covering:

1. Selecting all records
2. Selecting specific columns
3. Filtering using `WHERE`
4. Filtering prices
5. Filtering stock quantities
6. Sorting prices in ascending order
7. Sorting prices in descending order
8. Combining `WHERE` and `ORDER BY`
9. Filtering and sorting stock quantities
10. Filtering a price range using `BETWEEN`
